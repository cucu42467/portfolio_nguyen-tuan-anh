# Portfolio Nguyễn Tuấn Anh

Website portfolio giới thiệu dịch vụ kỹ thuật điện lạnh tại Hoàng Mai, Hà Nội. Giao diện cung cấp thông tin về dịch vụ, kinh nghiệm, quy trình làm việc, chính sách bảo hành và các phương thức liên hệ.

## Chạy dự án

```bash
npm install
npm run dev
```

## Kiểm tra và build

```bash
npm run lint
npm run test:once
npm run build
```

## Công nghệ

- React và TypeScript
- Vite
- Styled Components
